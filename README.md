# Content store

Saved articles and links, fetched to markdown, summarised, tagged and linked for Obsidian.
Grown with the `/tn-cstore-*` commands in Claude Code. Guide: `docs/tn-cstore-user-guide.md`.

**0 of 0 links fetched.**

## Start here

1. Create your own repo from this template (GitHub: "Use this template"), clone it.
2. Open Claude Code in the repo root and run `/tn-cstore-init`. It sets up the folders and asks for your first areas, projects and topics.
3. Open the repo root as an Obsidian vault.
4. Drop daily notes (`YYYY-MM-DD.md` with links) into `00_Staging/daily-notes/` or articles (`.md`, `.pdf`) into `00_Staging/articles/`, then run `/tn-cstore-ingest-daily` or `/tn-cstore-ingest-article`.

Needs Python 3 and `pip3 install --user -r tools/requirements.txt`.

## Structure

- `00_Staging/`: inbox. `daily-notes/` (files named `YYYY-MM-DD.md` with links), `articles/` (markdown or PDF).
- `raw/`: full text (`<slug>.md`, no links) and summaries (`<slug>.summary.md`, the only place with backlinks). `raw/attachments/` holds the images.
- `notes/`: generated hub notes (topics, people, entities, concepts) and `_index.md`.
- `01_Projects/`, `02_Areas/`: hand-written notes, created once and never overwritten.
- `03_Resources/`: for files you move in. `04_Archive/`: processed daily notes and PDFs.
- `tools/`: the scripts and the data (`classification.json`, `descriptions.py`, `para.py`, `urls.tsv`, `results.json`).
